My Cloud
Launchpad.

A hands-on project to learn how a website reaches the internet using Google Cloud, Docker and Nginx.

01 / INFRASTRUCTURE

Google Cloud

An Ubuntu virtual machine provides the compute resources. VPC firewall rules control inbound access.

02 / PACKAGING

Docker

The website and Nginx configuration are packaged into an image and run as a container.

03 / WEB SERVICE

Nginx

Nginx serves this static website from inside the container. The host maps HTTP port 80 to container port 80.

My learning objective
Understand the complete path from source files to a working cloud website, then practice updates, health checks, logs and cleanup.
